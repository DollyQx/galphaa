# G ALPHA Official Artist Photography Directory

Drop real high-resolution photographs of G ALPHA here:

1. `g_alpha_hero.jpg` - High-res editorial portrait / silhouette for Home Hero section.
2. `g_alpha_about.jpg` - Full portrait / studio composition for About Page.

Current fallback images are served from `/images/hero.png` and `/images/about.png`.
Replacing files in this folder updates the entire site automatically.
